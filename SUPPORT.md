# Support / 支援

## English

For help, bug reports or contract-format requests, open an issue at `https://github.com/pohsuntw-lab/ew-ai-power-digital-twin/issues`. Include the plugin version, schema version, expected result and actual result. Use a synthetic or redacted model; never attach passwords, API keys, EDC credentials, customer drawings or confidential logs.

## 繁體中文

如需協助、回報錯誤或提出資料契約需求，請至 `https://github.com/pohsuntw-lab/ew-ai-power-digital-twin/issues` 建立議題。請提供外掛版本、Schema 版本、預期結果與實際結果，並使用合成或脫敏模型；不得附上密碼、API Key、EDC 憑證、客戶圖紙或機密日誌。
